# Aplikasi Pemesanan dan Promosi Warung Lokal bagi Mahasiswa Asrama Telkom University

Aplikasi Pemesanan dan Promosi Warung Lokal bagi Mahasiswa Telkom University. Aplikasi ini dikembangkan berbasis Android dengan tujuan untuk mempermudah mahasiswa asrama Telkom University dalam mencari dan memesan makanan dari berbagai warung di sekitar kampus yang menyediakan layanan pengantaran. Target utama pengguna aplikasi ini adalah mahasiswa asrama Telkom University dan pemilik warung lokal di sekitar kampus. Melalui aplikasi ini, mahasiswa dapat menjelajahi daftar warung, melihat menu beserta harga, melakukan pemesanan, serta memberikan penilaian dan ulasan terhadap warung yang telah mereka coba. Sementara itu, pemilik warung dapat mengelola dan memperbarui menu mereka secara mandiri tanpa perlu promosi manual seperti brosur. Aplikasi ini diharapkan dapat menjadi solusi digital yang menghubungkan mahasiswa dengan warung lokal secara cepat, praktis, dan relevan dengan kebutuhan lingkungan kampus.
